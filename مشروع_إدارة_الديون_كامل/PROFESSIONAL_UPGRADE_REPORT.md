## التحسينات المنفذة

### 1. الشريط الجانبي القابل للإخفاء والإظهار

**الميزات المضافة:**
- زر Hamburger Menu في أعلى يمين كل صفحة
- انيميشن سلس (slide) من اليمين بمدة 300ms
- حفظ الحالة في localStorage (مفتاح: 'sidebar_visible')
- Responsive للشاشات المختلفة:
  - شاشات كبيرة (>768px): الشريط مفتوح افتراضياً
  - شاشات صغيرة (<768px): الشريط مخفي افتراضياً
- Backdrop شفاف على الشاشات الصغيرة
- المحتوى يتوسع تلقائياً عند إخفاء الشريط

**الملفات المنشأة:**
- `src/contexts/SidebarContext.tsx` - Context لإدارة حالة الشريط
- `src/components/HamburgerButton.tsx` - زر القائمة
- تحديث `src/components/MerchantSidebar.tsx` - إضافة الانيميشن
- تحديث `src/App.tsx` - دمج SidebarProvider

**الكود التقني:**
```typescript
// SidebarContext.tsx
- استخدام localStorage للحفظ
- useState لإدارة الحالة
- useEffect للحفظ التلقائي

// MerchantSidebar.tsx
- transition-transform duration-300
- translate-x-full للإخفاء
- translate-x-0 للإظهار

// App.tsx
- mr-60 عند الظهور
- mr-0 عند الإخفاء
- transition-all duration-300
```

1. الشريط الجانبي القابل للإخفاء مع جميع المتطلبات
2. Context لإدارة الحالة
3. حفظ الحالة في localStorage

## طريقة الاستخدام

### الشريط الجانبي:
1. انقر على زر القائمة (☰) في أعلى يمين الشاشة
2. الشريط سينزلق من اليمين بسلاسة
3. انقر مرة أخرى لإخفائه
4. الحالة تُحفظ تلقائياً

### على الشاشات الصغيرة:
- الشريط يغطي الشاشة بالكامل
- خلفية شفافة (backdrop) للإغلاق
- زر X في الشريط للإغلاق
- النقر على أي رابط يغلق الشريط تلقائياً
