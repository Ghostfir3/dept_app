## التفاصيل التقنية

### 1. تحديث عرض المبالغ في AllDebtsPage.tsx

#### التغييرات في دالة `loadDebts()`
```typescript
// جلب السدادات من جدول payment_transactions
const { data: paymentsData } = await supabase
  .from('payment_transactions')
  .select('debts_paid')
  .eq('merchant_id', profile.id);

// حساب المبلغ المسدد لكل دين
const paidAmounts: Record<string, number> = {};
if (paymentsData) {
  paymentsData.forEach(transaction => {
    if (transaction.debts_paid && Array.isArray(transaction.debts_paid)) {
      transaction.debts_paid.forEach((debtPaid: any) => {
        const debtId = debtPaid.debt_id;
        const amountPaid = debtPaid.amount_paid || 0;
        paidAmounts[debtId] = (paidAmounts[debtId] || 0) + amountPaid;
      });
    }
  });
}

// إضافة المبلغ المتبقي لكل دين
const debtsWithRemaining = data.map(debt => ({
  ...debt,
  paid_amount: paidAmounts[debt.id] || 0,
  remaining_amount: debt.amount - (paidAmounts[debt.id] || 0)
}));
```

#### تحديث بطاقات الإحصائيات
**من 5 إلى 6 بطاقات:**
1. **إجمالي الديون المتبقية** (أزرق) - يعرض المبلغ المتبقي فقط
2. **المبلغ المسدد** (أخضر) - جديد
3. **قيد الانتظار** (برتقالي)
4. **مدفوع كلياً** (رمادي)
5. **متأخر** (أحمر)
6. **العملاء** (بنفسجي)

#### تحديث جدول الديون
**الأعمدة الجديدة:**
- العميل
- رقم الهاتف
- **المبلغ المتبقي** (جديد - بخط عريض وأزرق)
- **المبلغ الأصلي** (جديد)
- **المبلغ المسدد** (جديد - بلون أخضر)
- الحالة
- تاريخ الاستحقاق
- الوصف
- تاريخ الإضافة
- الإجراءات (مع زر العين الجديد)

**ب. أزرار الإجراءات الرئيسية**

**ج. قائمة الديون التفصيلية**
كل دين يُعرض في بطاقة منفصلة تحتوي على:
- رقم الدين والحالة
- 3 بطاقات فرعية (المبلغ الأصلي، المسدد، المتبقي)
- تاريخ الاستحقاق والوصف
- زر تعديل

**د. النوافذ الفرعية**
1. **نافذة التسديد**: تُفتح عند الضغط على "تسديد"
2. **نافذة إضافة دين جديد**: تُفتح عند الضغط على "إضافة دين جديد"
3. **نافذة تعديل الدين**: تُفتح عند الضغط على "تعديل"

```typescript
// حساب المبلغ المتبقي لكل دين
const debtsWithRemaining = data.map(debt => ({
  ...debt,
  paid_amount: paidAmounts[debt.id] || 0,
  remaining_amount: debt.amount - (paidAmounts[debt.id] || 0)

// الإحصائيات الشاملة
const stats = {
  totalOriginal: debts.reduce((sum, d) => sum + d.amount, 0),
  totalPaid: debts.reduce((sum, d) => sum + (d.paid_amount || 0), 0),
  totalRemaining: debts.reduce((sum, d) => sum + (d.remaining_amount || d.amount), 0),
  count: debts.length
};
```
