## قاعدة البيانات وBackend

### تحديثات قاعدة البيانات
تم إعداد ملف SQL كامل: `database-migration-update.sql`

المحتوى:
```sql
-- عمود capital لجدول users_profile
ALTER TABLE users_profile ADD COLUMN IF NOT EXISTS capital DECIMAL(15, 2) DEFAULT 0;

-- عمود dispute_deadline لجدول debts
ALTER TABLE debts ADD COLUMN IF NOT EXISTS dispute_deadline TIMESTAMP WITH TIME ZONE;

-- سياسة RLS للعملاء
CREATE POLICY "Customers can update debt status" ON debts ...

-- فهرس للأداء
CREATE INDEX idx_debts_dispute_deadline ON debts ...
```

### Edge Function
تم إعداد: `supabase/functions/auto-confirm-debts/index.ts`

الوظيفة:
- البحث عن ديون معلقة > 24 ساعة
- تحديث الحالة إلى confirmed
- تسجيل التوقيت
