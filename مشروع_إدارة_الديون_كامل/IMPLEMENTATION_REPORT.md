## الميزات المنفذة

### المرحلة 1: تحسين صفحة رأس المال والأرباح ✅

**الملف**: `/src/pages/CapitalImpact.tsx`

#### 1. مؤشرات الأداء الرئيسية (KPIs)
تم إضافة 8 بطاقات إحصائية شاملة:
- رأس المال الأساسي
- صافي الربح
- عائد الاستثمار (ROI)
- هامش الربح
- إجمالي الإيرادات
- إجمالي المصروفات
- نمو الإيرادات (مقارنة بالشهر السابق)
- رأس المال المتاح

#### 2. حاسبة الأرباح التفاعلية
- حساب تلقائي للأرباح الصافية (الإيرادات - المصروفات)
- حساب هامش الربح (%)
- حساب عائد الاستثمار (ROI %)
- حساب نمو الإيرادات الشهري

#### 3. إدارة المصروفات الكاملة
**جدول قاعدة البيانات الجديد**: `expenses`

**الميزات**:
- ✅ إضافة مصروف جديد (مع فئات محددة)
- ✅ تعديل المصروفات الموجودة
- ✅ حذف المصروفات
- ✅ جدول عرض المصروفات مع التفاصيل
- ✅ تصنيف المصروفات (8 فئات)

**الفئات المتاحة**:
1. رواتب
2. إيجار
3. مواد خام
4. مرافق
5. نقل وشحن
6. تسويق
7. صيانة
8. أخرى

#### 4. الرسوم البيانية الشاملة (4 رسوم)

**أ. الإيرادات والمصروفات الشهرية** (Area Chart)
- عرض بيانات آخر 6 أشهر
- مقارنة الإيرادات والمصروفات
- ألوان متدرجة جميلة

**ب. توزيع رأس المال** (Pie Chart)
- رأس المال الحر
- رأس المال المقيد (في الديون)

**ج. مقارنة الإيرادات والمصروفات والأرباح** (Bar Chart)
- مقارنة شريطية ملونة
- عرض واضح للفرق

**د. المصروفات حسب الفئة** (Pie Chart)
- توزيع المصروفات على الفئات المختلفة
- ألوان متنوعة لكل فئة

#### 5. تحليل مالي ذكي وتوصيات
- تحليل صافي الربح (إيجابي/سلبي)
- تقييم عائد الاستثمار
- تنبيهات نسبة الديون
- تحليل نمو الإيرادات
- توصيات مالية تلقائية

### المرحلة 2: إنشاء صفحة جميع الديون ✅

**الملف الجديد**: `/src/pages/AllDebtsPage.tsx`  
**المسار**: `/merchant/all-debts`

#### 1. إحصائيات سريعة (5 بطاقات)
- إجمالي الديون
- قيد الانتظار
- مدفوع
- متأخر
- عدد العملاء

#### 2. نظام البحث والفلترة المتقدم
**البحث**:
- البحث بالاسم
- البحث برقم الهاتف
- البحث في الوصف

**الفلاتر**:
- جميع الحالات
- قيد الانتظار
- مؤكد
- مدفوع
- معترض عليه
- متأخر (فلتر ذكي حسب تاريخ الاستحقاق)

**الترتيب**:
- حسب التاريخ (تصاعدي/تنازلي)
- حسب المبلغ (تصاعدي/تنازلي)
- حسب اسم العميل (أبجدي)

#### 3. جدول الديون التفصيلي
**الأعمدة**:
- اسم العميل (مع أيقونة)
- رقم الهاتف (مع أيقونة)
- المبلغ (منسق)
- الحالة (مع أيقونات وألوان)
- تاريخ الاستحقاق (مع تنبيه للمتأخر)
- الوصف (قابل للاختصار)
- تاريخ الإضافة
- الإجراءات (تعديل / حذف)

**ميزات الجدول**:
- تمييز الديون المتأخرة (خلفية حمراء خفيفة)
- أيقونات توضيحية لكل عمود
- hover effects على الصفوف

#### 4. إدارة الديون الكاملة

**إضافة دين جديد**:
- Modal منبثق جميل
- حقول: الاسم، الهاتف، المبلغ، تاريخ الاستحقاق، الوصف
- التحقق من صحة البيانات
- رسائل نجاح/فشل

**تعديل دين**:
- Modal تعديل مع عرض البيانات الحالية
- إمكانية تعديل جميع الحقول
- حقل "سبب التعديل" (اختياري)
- حفظ التغييرات في سجل التحديثات

**حذف دين**:
- تأكيد قبل الحذف
- رسالة تحذير واضحة
- حذف فوري من قاعدة البيانات

#### 5. التصميم المتجاوب
- يعمل بشكل ممتاز على جميع الأحجام
- جداول قابلة للتمرير أفقياً
- بطاقات متجاوبة (grid responsive)

### المرحلة 3: التحديثات الشاملة ✅

#### 1. تحديث المسارات (App.tsx)
```typescript
<Route path="/merchant/all-debts" element={
  <PrivateRoute allowedType="merchant">
    <MerchantLayout>
      <AllDebtsPage />
    </MerchantLayout>
  </PrivateRoute>
} />
```

#### 2. تحديث القائمة الجانبية (MerchantSidebar.tsx)
- إضافة عنصر قائمة جديد: "جميع الديون"
- أيقونة: List
- المسار: `/merchant/all-debts`
- الترتيب: بعد "إضافة دين" مباشرة

#### 3. تحديث قاعدة البيانات
**جدول جديد**: `expenses`

**الهيكل**:
```sql
- id: UUID (مفتاح أساسي)
- merchant_id: UUID (مرجع للتاجر)
- amount: NUMERIC (المبلغ)
- category: TEXT (الفئة)
- description: TEXT (الوصف)
- expense_date: DATE (التاريخ)
- created_at: TIMESTAMP (تاريخ الإنشاء)
```

**الأمان**:
- Row Level Security (RLS) مفعّل
- سياسات للقراءة والإضافة والتعديل والحذف
- كل تاجر يرى مصروفاته فقط

#### 4. تحديث الأنواع (supabase.ts)
```typescript
export interface Expense {
  id: string;
  merchant_id: string;
  amount: number;
  category: string;
  description: string | null;
  expense_date: string;
  created_at: string;
}
```

## كيفية الاستخدام

3. أدخل رأس المال الأساسي واحفظه

6. عدّل أو احذف المصروفات من الجدول
