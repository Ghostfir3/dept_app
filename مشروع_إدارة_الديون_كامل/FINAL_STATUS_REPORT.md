### ⚠️ إلزامي لتفعيل ميزة "ملاحظات العملاء"

يجب تنفيذ الخطوات التالية في Supabase Dashboard:

#### الخطوة 1: إنشاء جدول customer_notes

1. افتح Supabase Dashboard: https://supabase.com/dashboard/project/srkgtzvgjlysjmkpfaau
2. انتقل إلى **SQL Editor**
3. انسخ والصق محتوى الملف: `database-customer-notes.sql`
4. اضغط على **RUN**

**ما سيتم إنشاؤه:**
```sql
CREATE TABLE customer_notes (
  id UUID PRIMARY KEY,
  merchant_id UUID REFERENCES users_profile(id),
  customer_phone VARCHAR(20),
  customer_name VARCHAR(255),
  note_text TEXT,
  created_at TIMESTAMP,
  updated_at TIMESTAMP
);
-- + فهارس + سياسات RLS
```

#### الخطوة 2: التأكيد التلقائي للديون (اختياري)

لتفعيل ميزة التأكيد التلقائي بعد 24 ساعة، يمكن نشر Edge Function:

**الملف:** `supabase/functions/auto-confirm-debts/index.ts`

**الأمر:**
```bash
supabase functions deploy auto-confirm-debts --project-ref srkgtzvgjlysjmkpfaau
```

**ملاحظة:** هذه الميزة اختيارية. الواجهة الأمامية تعرض مؤقت العد التنازلي بشكل صحيح حتى بدون Edge Function.
