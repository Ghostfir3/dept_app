## التحقق من صحة البيانات

### الصيغ المستخدمة

**صافي الربح**:
```
صافي الربح = إجمالي الإيرادات - إجمالي المصروفات
```

**هامش الربح**:
```
هامش الربح (%) = (صافي الربح ÷ إجمالي الإيرادات) × 100
```

**عائد الاستثمار (ROI)**:
```
ROI (%) = (صافي الربح ÷ رأس المال) × 100
```

**نمو الإيرادات**:
```
نمو الإيرادات (%) = ((إيرادات الشهر الحالي - إيرادات الشهر السابق) ÷ إيرادات الشهر السابق) × 100
```

**يرجى التحقق من صحة هذه الحسابات خلال الاختبار اليدوي**.
