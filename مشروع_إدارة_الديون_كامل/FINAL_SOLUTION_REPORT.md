## 🔄 **كيفية عمل النظام الآن:**

### **عند إضافة دين جديد:**
1. التاجر يدخل بيانات العميل والمبلغ
2. النظام يجلب معلومات التاجر تلقائياً
3. يتم حفظ الدين مع `merchant_name` و `merchant_phone`
4. **إرسال إشعار تلقائي للعميل**
5. العميل يرى الدين مع اسم التاجر الصحيح

### **في واجهة العميل:**
1. الشريط السفلي يظهر في جميع الصفحات
2. صفحة التجار تعرض جميع التجار بإحصائيات مفصلة
3. الإشعارات تعمل وتظهر الديون الجديدة
4. أسماء التجار تظهر بشكل صحيح
