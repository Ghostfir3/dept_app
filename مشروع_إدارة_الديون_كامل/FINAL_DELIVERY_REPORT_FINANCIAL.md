### 2. قاعدة البيانات الجديدة

**الجداول المنشأة:**

#### جدول capital (رأس المال)
```sql
- id: UUID (مفتاح أساسي)
- user_id: UUID (مرجع للمستخدم)
- initial_capital: DECIMAL (رأس المال الأساسي)
- current_balance: DECIMAL (الرصيد الحالي)
- notes: TEXT (ملاحظات)
- last_updated: TIMESTAMP
- created_at: TIMESTAMP
```

#### جدول expenses (المصروفات)
```sql
- id: UUID
- merchant_id: UUID
- category: VARCHAR (7 فئات: مواصلات، طعام، إيجار، كهرباء، مكاتب، عمالة، أخرى)
- amount: DECIMAL
- description: TEXT
- expense_date: DATE
- created_at: TIMESTAMP
```

#### جدول revenue (متوسط الأرباح)
```sql
- id: UUID
- user_id: UUID
- daily_average: DECIMAL (متوسط يومي)
- monthly_total: DECIMAL (إجمالي شهري)
- year_total: DECIMAL (إجمالي سنوي)
- revenue_date: DATE
- notes: TEXT
- created_at: TIMESTAMP
```

#### جدول analytics_insights (التحليلات)
```sql
- id: UUID
- user_id: UUID
- analysis_date: DATE
- expense_to_revenue_ratio: DECIMAL (نسبة المصروفات للإيرادات)
- roi: DECIMAL (عائد الاستثمار)
- daily_growth_rate: DECIMAL (معدل النمو اليومي)
- debt_to_capital_ratio: DECIMAL (نسبة الديون لرأس المال)
- recommendations: JSONB (توصيات ذكية)
- metrics: JSONB (مقاييس)
- created_at: TIMESTAMP
```

**الحماية والأمان:**
- Row Level Security (RLS) مفعل على جميع الجداول
- سياسات أمان دقيقة لكل مستخدم
- فهارس محسنة للأداء العالي

### 3. الصفحات المطورة (411 + 523 + 378 + 440 = 1,752 سطر كود)

#### أ) صفحة إدارة رأس المال (/merchant/capital-management)
**المميزات:**
- 4 بطاقات معلومات رئيسية:
  - رأس المال الأساسي
  - الرصيد الحالي
  - التغير في رأس المال
  - نسبة التغير
- نموذج إدخال/تحديث مع حقلين:
  - رأس المال الأساسي
  - الرصيد الحالي
  - ملاحظات
- رسمان بيانيان تفاعليان:
  - تطور رأس المال عبر الزمن (Line Chart)
  - التغيرات في رأس المال (Area Chart)
- جدول سجل التعديلات الكامل
- نظام نصائح ذكي حسب الأداء

**الاختبار:**
- تم إدخال رأس مال أساسي: 50,000 ريال
- رصيد حالي: 55,000 ريال
- النتيجة: نمو 10% - نصيحة إيجابية

#### ب) صفحة إدارة المصروفات (/merchant/expenses)
**المميزات:**
- 3 بطاقات ملخصة:
  - إجمالي المصروفات
  - المصروفات الشهرية
  - المصروفات السنوية
- نظام تصفية متقدم:
  - حسب الفئة (7 فئات)
  - حسب الشهر
- نموذج إضافة/تعديل مصروف كامل
- رسمان بيانيان:
  - توزيع المصروفات حسب الفئة (Pie Chart)
  - المصروفات الشهرية (Bar Chart)
- جدول تفاعلي مع خيارات تعديل وحذف
- ألوان مميزة لكل فئة

**الفئات المدعومة:**
1. مواصلات (أزرق)
2. طعام (أخضر)
3. إيجار (برتقالي)
4. كهرباء (أحمر)
5. مكاتب (بنفسجي)
6. عمالة (وردي)
7. أخرى (رمادي)

**الاختبار:**
- تم إضافة مصروف إيجار: 5,000 ريال
- النتيجة: تحديث فوري للبطاقات والرسوم البيانية

#### ج) صفحة متوسط الأرباح (/merchant/revenue)
**المميزات:**
- 4 بطاقات رئيسية:
  - متوسط الربح اليومي
  - الربح الشهري المتوقع
  - الربح السنوي المتوقع
  - معدل النمو
- نموذج إدخال بسيط:
  - متوسط الربح اليومي
  - حساب تلقائي للشهري والسنوي
  - ملاحظات
- رسمان بيانيان:
  - تطور متوسط الربح اليومي (Area Chart)
  - الأرباح المتوقعة (Line Chart)
- رسم بياني للتوقعات المستقبلية (3 أشهر):
  - سيناريو متشائم
  - سيناريو متوقع
  - سيناريو متفائل
- جدول سجل الأرباح الكامل

**الاختبار:**
- إدخال متوسط يومي: 1,500 ريال
- الحساب التلقائي:
  - شهري: 45,000 ريال (1,500 × 30)
  - سنوي: 547,500 ريال (1,500 × 365)
- النتيجة: دقة 100% في الحسابات

#### د) صفحة التحليلات المالية (/merchant/financial-analytics)
**المميزات الأساسية:**

**1. المؤشرات الرئيسية (5 KPIs):**
- رأس المال الحالي
- الإيرادات الشهرية
- المصروفات الشهرية
- الديون المتبقية
- صافي الربح

**2. الرسوم البيانية:**
- رسم دائري للنظرة المالية العامة (Pie Chart)
- رسم رادار لمؤشرات الأداء (Radar Chart):
  - الربحية
  - السيولة
  - الكفاءة
  - النمو
  - الاستقرار

**3. المؤشرات التفصيلية (4 بطاقات):**
- نسبة المصروفات للإيرادات
- عائد الاستثمار (ROI)
- معدل النمو اليومي
- نسبة الديون لرأس المال

**4. نظام التوصيات الذكي:**
يقوم بتحليل البيانات تلقائياً ويقدم توصيات حسب الأداء:

**أنواع التوصيات:**
- **نجاح** (أخضر): عندما الأداء ممتاز
- **تحذير** (برتقالي): عندما هناك مجال للتحسين
- **خطر** (أحمر): عندما تحتاج تدخل فوري

**معايير التحليل:**
- نسبة المصروفات > 70% → تحذير
- نسبة المصروفات < 30% → إشادة
- ROI > 20% → ممتاز
- ROI < 5% → يحتاج تحسين
- نسبة ديون > 75% → خطر
- نسبة ديون > 50% → تحذير
- نمو > 10% → قوي
- نمو < -10% → انخفاض

**الاختبار:**
- البيانات المدخلة:
  - رأس المال: 55,000
  - الإيرادات: 45,000
  - المصروفات: 5,000
  - الديون: 0
- النتائج المحسوبة:
  - صافي الربح: 40,000 ريال (دقيق 100%)
  - نسبة المصروفات: 11.1% (ممتاز)
  - ROI: (حساب تلقائي)
- التوصيات: إيجابية بناءً على الأداء الممتاز
