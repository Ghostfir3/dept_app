# تعليمات تطبيق تحديثات قاعدة البيانات

## خطوات التنفيذ

### 1. إنشاء جدول ملاحظات العملاء

يجب تنفيذ الملف `database-customer-notes.sql` في Supabase Dashboard:

1. افتح Supabase Dashboard: https://supabase.com/dashboard/project/srkgtzvgjlysjmkpfaau
2. انتقل إلى SQL Editor
3. انسخ والصق محتوى الملف `database-customer-notes.sql`
4. اضغط على RUN لتنفيذ SQL

### 2. النتائج المتوقعة

بعد تنفيذ SQL سيتم:
- ✅ إنشاء جدول `customer_notes` مع الأعمدة: id, merchant_id, customer_phone, customer_name, note_text, created_at, updated_at
- ✅ إضافة سياسات RLS للتحكم في الوصول (التاجر يمكنه قراءة/كتابة ملاحظاته فقط)
- ✅ إضافة فهارس لتحسين الأداء

### 3. التحقق من نجاح التنفيذ

1. انتقل إلى Table Editor في Supabase Dashboard
2. تحقق من وجود جدول `customer_notes`
3. تحقق من أن الجدول يحتوي على الأعمدة الصحيحة

## الميزات الجديدة المضافة

### ✅ 1. تقليل عرض القائمة الجانبية
- تم تقليل عرض Sidebar من 256px إلى 240px

### ✅ 2. صفحة التقارير المتقدمة
- **المسار**: `/merchant/reports`
- **الميزات**:
  - تقارير يومية/أسبوعية/شهرية
  - اختيار شهر وسنة مخصصة
  - إحصائيات شاملة (إجمالي، مدفوع، معلق، معدل السداد)
  - رسوم بيانية (PieChart، BarChart)
  - جدول أفضل 10 عملاء
  - تصدير PDF مع الإحصائيات والرسوم البيانية

### ✅ 3. نظام التنبيهات الذكية
- **المسار**: `/merchant/notifications`
- **الميزات**:
  - عداد غير المقروءة في Sidebar (شارة حمراء)
  - تنبيهات تلقائية للديون المعلقة، المؤكدة، المعترض عليها، المتأخرة
  - فلترة (الكل / غير المقروءة)
  - تعليم الكل كمقروء
  - حذف التنبيهات
  - ألوان مميزة لكل نوع تنبيه

### ✅ 4. البحث المتقدم في إدارة الديون
- **المسار**: `/merchant/debts`
- **التحسينات**:
  - بحث نصي في الاسم، رقم الهاتف، والوصف
  - فلترة حسب الحالة
  - **فلاتر متقدمة**:
    - نطاق المبلغ (من - إلى)
    - نطاق التاريخ (من تاريخ - إلى تاريخ)
    - زر إعادة تعيين الفلاتر
  - عرض عدد النتائج المطابقة

### ✅ 5. صفحة ملاحظات العملاء
- **المسار**: `/merchant/notes`
- **الميزات**:
  - إضافة ملاحظات جديدة (رقم هاتف، اسم، نص الملاحظة)
  - تعديل الملاحظات الموجودة
  - حذف الملاحظات
  - بحث في الملاحظات (اسم، رقم، نص)
  - إحصائيات (إجمالي، عدد العملاء، ملاحظات الأسبوع)
  - عرض شبكي جميل مع تواريخ الإنشاء والتحديث

### ✅ 6. حاسبة صافي الربح
- **المسار**: `/merchant/net-profit`
- **الميزات**:
  - إدخال المصروفات (7 فئات): تشغيلية، ضرائب، رواتب، إيجار، مرافق، تسويق، أخرى
  - حساب تلقائي لصافي الربح (الإيرادات - المصروفات)
  - حساب هامش الربح بالنسبة المئوية
  - رسوم بيانية:
    - PieChart: توزيع المصروفات
    - BarChart: مقارنة الإيرادات والمصروفات وصافي الربح
    - LineChart: الإيرادات الشهرية (آخر 6 أشهر)
  - نصائح لتحسين الأرباح

### ✅ 7. الإحصائيات المتقدمة
- **المسار**: `/merchant/statistics`
- **الميزات**:
  - بطاقات ملخص (إجمالي المبلغ، معدل السداد، متوسط الدين، عدد العملاء)
  - اختيار الفترة الزمنية (أسبوع / شهر / سنة)
  - رسوم بيانية متعددة:
    - PieChart: توزيع حالات الديون
    - BarChart: توزيع المبالغ حسب النطاق
    - AreaChart: الأداء الزمني (مدفوع/معلق)
  - جدول أفضل 5 عملاء مع تفاصيل كاملة
